# Laravel Truss Schema Visualizer & ERD Project

An interactive Database Schema Visualizer and Entity-Relationship Diagram (ERD) project built on **Laravel 13** and **MySQL 8+**, utilizing the `albertoarena/laravel-truss` package. 

This repository serves as a pre-configured boilerplate and blueprint for a **Multi-Tenant Mess & Meal Management System**. It provides full database migration structures, relationships, and an intuitive UI to explore database tables and model connections seamlessly.

## Features

- **Laravel 13 Architecture**: Latest migration features, composite indexes, foreign key constraints, and cascade operations.
- **Pre-built Mess System Database**:
  - Super Admin & Multi-User Management
  - Multi-Group / Mess system (Users can own or join multiple messes)
  - Invitation / Join request workflow with approval states
  - Monthly accounting cycles, deposit tracking, daily meal logs, and itemized bazar expenses
- **Interactive Visual ERD**: Integrated with `albertoarena/laravel-truss` for interactive table relationship graphs.

---

## Requirements

Ensure your environment meets the following minimum prerequisites:

- **PHP**: `^8.2` or higher
- **Composer**: `^2.x`
- **MySQL / MariaDB**: MySQL `8.0+` recommended
- **Node.js & NPM**: (Optional, for frontend assets)
